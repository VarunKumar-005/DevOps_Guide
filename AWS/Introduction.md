## Benefits of AWS
- ***Trade fixed expense for variable expense***: By using the AWS Cloud, businesses can transition from fixed investments to variable costs.
- ***Benefit from massive economies of scale***: As AWS buys all hardware and devices in bulk its charges is considerably lower the charge for creating and managing instance for a end user is significantly lower.
- ***capacity*** : AWS cloud helps us to scale the application in minutes provisioning the hardware and the maintainance on AWS side.
- ***Increase speed and agility*** : With the cloud, businesses can rapidly deploy applications and services.
- ***global in minutes*** : As AWS cloud centres is all over the world it is easier to deploy in **INDIA** and view in **US**
